# 个人网站风格参考（Style References）

**用途**：为 `PRD.md` 第 9 章提供风格选择依据
**日期**：2026-10-21

---

## 一、筛选原则

「科技感 + 高级感 + 简洁」三个词很容易互相打架 —— 科技感容易滑向特效堆砌，高级感容易被误读成大色块。以下所有参考均满足：

- 信息密度可控，首屏讲清一件事
- 无满屏粒子 / 视差 / 光斑
- 排版承担主要视觉表现（字距、字号级差、留白）
- 色彩克制，强调色只用在一个地方

## 三、三个候选风格方案（具体到设计 token）

### 方案 A：Obsidian Grid（黑曜石网格）

**一句话**：近黑底色上的精密网格，像一张架构图。

| Token | 值 |
|---|---|
| 背景 | `#0B0D10`（近黑，带一点点蓝） |
| 卡片面 | `#12151A` |
| 主文字 | `#E8EAED` |
| 次文字 | `#8B92A0` |
| 分隔线 | `#1E232B` |
| 强调色 | `#3DDC97`（冷青绿，仅用于 CTA、时间轴节点、当前导航） |
| 字体 | 中文：`PingFang SC` / `Source Han Sans`；英文与数字：`Inter`；元信息：`JetBrains Mono` |
| 字号 | 12 / 14 / 16 / 20 / 32 / 56（px） |
| 行高 | 正文 1.75，标题 1.2 |
| 圆角 | 8px（卡片）/ 6px（标签）/ 999px（药丸） |
| 间距基数 | 8px |
| 背景细节 | 极淡的 1px 网格（透明度 3%–5%），仅在 hero 区域出现 |
| 动效 | 无 loader；区块标题 200ms 淡入；卡片悬停边框变色 |

**适合**：希望「一眼看出是技术专家」，接受深色主调。

**风险**：深色站看久了容易疲劳；打印/截图投递时观感偏暗。

---

### 方案 B：Paper White（纸白极简）

**一句话**：像一份排印精美的技术白皮书。

| Token | 值 |
|---|---|
| 背景 | `#FFFFFF`，区块交替时用 `#FAFAFA` |
| 卡片面 | `#FFFFFF` + 1px `#E6E6E6` 边框（不用阴影） |
| 主文字 | `#111111` |
| 次文字 | `#6E6E6E` |
| 分隔线 | `#EBEBEB` |
| 强调色 | `#111111`（纯黑做强调）+ `#1A56DB` 仅用于链接与 CTA |
| 字体 | 中文：`PingFang SC` / `Source Han Serif` 用于大标题；英文：`Inter`；数字：`tabular-nums` 等宽数字 |
| 字号 | 13 / 15 / 17 / 22 / 40 / 64 |
| 行高 | 正文 1.8，标题 1.15 |
| 圆角 | 4px（卡片）/ 4px（标签）——**刻意用小圆角**，减少「App 感」 |
| 间距基数 | 8px，区块纵向间距 96px（桌面）/ 64px（移动） |
| 背景细节 | 无网格；hero 右上角可有一个极淡的径向光晕（透明度 4%） |
| 动效 | 仅悬停颜色变化 + 区块标题 200ms 淡入 |

**适合**：想让面试官觉得「稳重、靠谱、有品位」，且重视可读性。

**风险**：科技感需要靠细节（等宽数字、细线、精确对齐）撑，做得不好会显得平淡。

---

### 方案 C：Slate Terminal（石板终端）

**一句话**：冷灰底 + 琥珀强调，像一块高级 IDE。

| Token | 值 |
|---|---|
| 背景 | `#14161A`（冷灰黑） |
| 卡片面 | `#1B1E24` |
| 主文字 | `#DCDEE3` |
| 次文字 | `#8A9099` |
| 分隔线 | `#282C34` |
| 强调色 | `#E8A33D`（琥珀）/ 次强调 `#4C9AFF` |
| 字体 | 正文 `Inter` / 中文 `PingFang SC`；**全站元信息用等宽** `JetBrains Mono` |
| 字号 | 12 / 13 / 15 / 19 / 30 / 52 |
| 行高 | 正文 1.7 |
| 圆角 | 6px |
| 间距基数 | 8px |
| 背景细节 | 顶部一条 2px 滚动进度条；区块编号如 `01 — 关于`；导航右侧显示本地时间 |
| 动效 | 打字机效果仅用于 hero 一句话（且尊重 reduced-motion） |

**适合**：想突出「极客/工程师」气质，有个性。

**风险**：等宽字体用得过多会降低中文阅读舒适度，需严格控制范围。

## 四、推荐组合（如果不想三选一）

**B 的骨架 + A 的强调色 + 5 号参考的细节**

- 主背景：白 / 近白（Paper White 的留白与可读性）
- 强调色：`#3DDC97` 冷青绿只用 3 处（主 CTA、时间轴节点、当前导航下划线）
- 元信息：JetBrains Mono 标注时间、技术栈、学习研究类型
- 分隔：1px `#EBEBEB` 细线，不用卡片阴影
- 动效：只有 200ms 的颜色/边框变化

这样既有「深色科技站」的锐利感，又保留白底的长期可读性与高级感。

## 六、通用细节清单（无论选哪个方案都用得上）

这些是「高级感」的真正来源，成本低但效果显著：

1. **只用 3–4 个字号**，级差明确（如 15 / 17 / 22 / 40），不要 14/16/18 这种含混级差
2. **数字用等宽字体**（`font-variant-numeric: tabular-nums`），年份、百分比对齐才会整齐
3. **标签用极小号 + 大写字距**（12px，letter-spacing 0.08em）
4. **不要纯黑纯白**（`#111` / `#FAFAFA` 比 `#000` / `#FFF` 更有质感）
5. **分隔线代替卡片阴影**，视觉更干净
6. **悬停只改颜色，不改尺寸**，避免布局跳动
7. **留白是设计**：区块纵向间距 ≥64px，不要在窄容器里塞满内容
8. **对齐比装饰重要**：时间轴的年份右对齐、标签左对齐、正文最大宽度 68ch
